# Experiment 2 – Frontend UI Using React

## Objective
To design and implement a responsive frontend user interface using React and modern UI libraries such as Bootstrap and Material UI.

---

## Files Included
1. File 1 – Designed a student form as a responsive UI using Bootstrap components.
2. File 2 – Designed a card-based UI layout using React and Bootstrap components.
3. File 3 – Designed a user interface using Material UI, a React-based component library that provides ready-to-use components.
4. File 4 – Designed a responsive navigation bar using a UI component library.
5. Case Study – Hershy’s Kitchen is a responsive food-ordering website built using React that allows users to explore multi-cuisine menus, customize dishes based on preferences, and place orders seamlessly. The platform focuses on an intuitive user experience with modern UI components, smooth navigation, and visually appealing layouts.

---

## Technologies Used
- React.js  
- Vite  
- Bootstrap  
- Material UI  
- HTML5  
- CSS3  
- JavaScript (ES6)
